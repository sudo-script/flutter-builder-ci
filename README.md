# calc

Generated by Glassbox — a React 18 + Vite app packaged for Android with Capacitor.

- App id: `com.cal.c`
- Version: `1.0.0`

## Run in a browser

```bash
npm install
npm run dev
```

## Build the APK locally

```bash
npm install
npm run build              # vite build → dist/
npx cap add android        # first time only
node scripts/apply-android-resources.mjs
npx cap sync android
cd android && ./gradlew assembleDebug
```

The APK lands in `android/app/build/outputs/apk/debug/app-debug.apk`.

## Layout

| Path | What it holds |
|------|---------------|
| `src/App.jsx` | Router — one route per screen |
| `src/screens/` | One component per screen |
| `src/lib/DesignFrame.jsx` | Scales the 390-wide design to any phone width |
| `src/lib/storage.js` | Persistence shared by every screen |
| `src/lib/assets.js` | Named constants for bundled images and media |
| `src/models/`, `src/data/` | Contract-generated models and stores |
| `android-resources/` | Launcher icons applied after `cap add android` |
